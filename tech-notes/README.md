# Tech Notes

Technical notes and learning resources covering Rust, databases, and system design.

## Live Site

This site is deployed at [tech-notes.maryammasinan.me](https://tech-notes.maryammasinan.me)

## Development

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

## Structure

- `rust/` - Notes about Rust programming language
- `database/` - Database concepts and patterns
- `system-design/` - System design patterns and implementations

## Deployment

This project is configured for Vercel deployment with static export.

1. Push to your Git repository
2. Import the project in Vercel
3. Configure the subdomain in Vercel's domain settings
4. Deploy!
